\# PyTorch MNIST Digit Recognizer



A handwritten digit recognition application built with Python, PyTorch and Tkinter.



The user can draw a digit from 0 to 9 with the mouse and the neural network predicts the digit.



The application also supports human-in-the-loop correction: if the model makes a mistake, the user can provide the correct label and the model can be fine-tuned using the corrected example.



\## Features



\- Handwritten digit recognition

\- PyTorch neural network

\- CUDA GPU support

\- Tkinter graphical interface

\- MNIST preprocessing

\- Prediction probabilities for digits 0-9

\- User correction system

\- Incremental fine-tuning

\- Saved user corrections

\- Model persistence



\## Technologies



\- Python

\- PyTorch

\- TorchVision

\- CUDA

\- Tkinter

\- Pillow

\- MNIST
